# GRID — CRGGR Canvas Theme

Shopify Liquid theme for the CRGGR storefront, live on the `crggr` store. It was generated by Sidekick in Shopify's Canvas storefront editor and is now maintained in this repo.

> **Heads up:** this repo changes frequently. The theme is edited in Canvas, and those changes are synced back here, so expect regular churn in blocks, templates, styles, and settings.

The visual language, called **GRID**, is flat, hairline-stroke and true black, like a sci-fi control room. Colour appears only where it carries meaning. See [DESIGN.md](DESIGN.md) for the full design contract.

## Structure

| Path | Purpose |
| --- | --- |
| `layout/` | Global shell (`theme.liquid`, `password.liquid`) |
| `templates/` | Liquid page templates; each composes its page from blocks |
| `blocks/` | Reusable, merchant-editable visual primitives (including the desktop-style `frame`, `desktop`, `dock` and `header` blocks) |
| `snippets/` | Internal utilities (icons, drawers, cart pieces, OS window chrome, wallpaper, social links) |
| `assets/` | One custom element per JS file (`s-*.js`), plus icons |
| `config/styles.css` | The single Tailwind v4 CSS source |
| `config/settings_*.json` | Theme settings schema and live values |
| `locales/` | Translations (runtime and schema) |

This is simply how Canvas works: there is no `sections/` folder, no JSON templates, no schema presets, and no component CSS files. Styling uses Tailwind utilities and theme tokens. The entire repo reflects the code generated from Schema, and any manual edits will be noted. [AGENTS.md](AGENTS.md) covers composition, styling, JS, and translation rules.

## Interface model

The storefront presents itself as a small operating system: pages open as windows (`s-window`, `s-window-manager`), navigation lives in a dock (`s-dock`) and a spotlight search (`s-spotlight`), and the background is an animated wallpaper grid (`s-wallpaper`). Storefront behaviour such as the cart, compare, recently viewed items and product forms is built from the same plain custom elements. The password page has its own layout and template (`layout/password.liquid`, `templates/password.liquid`).

## CSS

Author styles in `config/styles.css`. Canvas/Sidekick compiles that file to `assets/styles.min.css`, which is generated output and **git-ignored**. Never edit it by hand.
